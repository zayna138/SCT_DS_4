# SCT_DS_4 - Traffic Accident Data Analysis

## Objective

Analyze traffic accident data to identify patterns related to road conditions, weather, and time of day.

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Description

This project analyzes traffic accident datasets to identify accident hotspots and contributing factors through visualization and analysis.

## Features

* Data cleaning
* Accident trend analysis
* Visualization of hotspots
* Pattern identification

## Dataset

Traffic Accident Dataset.

## Learning Outcomes

* Data analysis techniques
* Visualization methods
* Pattern recognition
* Insight generation
