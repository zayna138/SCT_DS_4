# SCT_DS_4 - Traffic Accident Data Analysis

This project analyzes traffic accident data to identify trends and patterns using Python.

## Objective

Analyze traffic accident data and visualize important insights related to accidents.

## Dataset

US Accidents Dataset

## Libraries Used

- Pandas
- Matplotlib

## Analysis Performed

1. Loaded and explored the dataset
2. Checked missing values
3. Analyzed accident severity distribution
4. Analyzed weather conditions during accidents
5. Visualized temperature distribution

## Visualizations

- Accident Severity Distribution
- Weather Condition Analysis
- Temperature Distribution Histogram

## Output

The project provides insights into accident trends, severity levels, and weather conditions affecting road accidents.
